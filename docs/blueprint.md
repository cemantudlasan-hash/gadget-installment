# **App Name**: GadgetInstall

## Core Features:

- Dashboard Interface: Display sales, commission, and pricing data in an organized, tabbed interface.
- Sales Management: Add, edit, and delete sales records with customer and product details, payment schedules and status.
- Income/Expense Ledger: Input expenses or commissions to reflect them in the ledger.
- Pricing Calculator: Configure purchase price and markup, then dynamically calculate prices
- Receipt Generation: Generates and prints a customizable receipt for each sale with key customer and payment information.
- AI-Enhanced Note Suggestions: AI tool assists with suggesting a customer note/reminder. If customer's ID/passport is abnormal, then AI can add a reminder.
- Client-Side Form Validations: Implements client-side form validation to make sure input is within reasonable range before submission to API

## Style Guidelines:

- Primary color: Indigo (#4F46E5) for a professional and trustworthy feel.
- Background color: Light gray (#F9FAFB), a very slightly tinted desaturated version of the primary, provides a clean backdrop.
- Accent color: Purple (#8B5CF6), a more saturated and brighter analogous hue, to highlight interactive elements.
- Body and headline font: 'Inter' (sans-serif) for a modern and readable design.
- Simple line icons from a consistent set for visual clarity and easy recognition.
- Card-based layout with rounded corners and subtle shadows to create depth and separation between sections.
- Subtle transitions and hover effects to enhance user interaction and provide feedback.
